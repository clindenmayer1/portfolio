# Chris Lindenmayer — Portfolio

Personal portfolio site. Static HTML, no build step.

| Page | |
|---|---|
| `index.html` | Home — hero, scroll-driven project slider |
| `envision.html` | Envision — virtual design center case study |
| `teledynamics.html` | Teledynamics — B2B commerce case study |
| `site-nav.js` | Shared `<site-nav>` custom element used by every page |

`envision-design-system/packages/developer-center/dist/` is a built copy of the
Envision Design Center, linked from the Envision case study.
